# TK1917 flight status example (September 29, 2026)

A live example of the FlightNerve `/airline` endpoint for **TK1917** (Turkish Airlines, Istanbul to Geneva), captured on September 29, 2026.

Get a free API key at [flightnerve.com/register](https://flightnerve.com/register/) and see the [endpoint reference](../docs/ENDPOINTS.md).

## Request

```bash
curl "https://api.flightnerve.com/airline/YOUR_API_KEY?num=1917&name=TK&date=20260929"
```

The API key goes in the URL path. Flight number is digits only (`num`); airline is the IATA or ICAO code (`name`); `date` is `YYYYMMDD`.
