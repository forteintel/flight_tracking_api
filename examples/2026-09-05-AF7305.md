# AF7305 flight status example (September 5, 2026)

A live example of the FlightNerve `/airline` endpoint for **AF7305** (Air France, Paris to Nice), captured on September 5, 2026.

Get a free API key at [flightnerve.com/register](https://flightnerve.com/register/) and see the [endpoint reference](../docs/ENDPOINTS.md).

## Request

```bash
curl "https://api.flightnerve.com/airline/YOUR_API_KEY?num=7305&name=AF&date=20260905"
```

The API key goes in the URL path. Flight number is digits only (`num`); airline is the IATA or ICAO code (`name`); `date` is `YYYYMMDD`.
