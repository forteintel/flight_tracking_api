# QR1002 flight status example (October 23, 2026)

A live example of the FlightNerve `/airline` endpoint for **QR1002** (Qatar Airways, Doha to Dubai), captured on October 23, 2026.

Get a free API key at [flightnerve.com/register](https://flightnerve.com/register/) and see the [endpoint reference](../docs/ENDPOINTS.md).

## Request

```bash
curl "https://api.flightnerve.com/airline/YOUR_API_KEY?num=1002&name=QR&date=20261023"
```

The API key goes in the URL path. Flight number is digits only (`num`); airline is the IATA or ICAO code (`name`); `date` is `YYYYMMDD`.
