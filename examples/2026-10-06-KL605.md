# KL605 flight status example (October 6, 2026)

A live example of the FlightNerve `/airline` endpoint for **KL605** (KLM, Amsterdam to Los Angeles), captured on October 6, 2026.

Get a free API key at [flightnerve.com/register](https://flightnerve.com/register/) and see the [endpoint reference](../docs/ENDPOINTS.md).

## Request

```bash
curl "https://api.flightnerve.com/airline/YOUR_API_KEY?num=605&name=KL&date=20261006"
```

The API key goes in the URL path. Flight number is digits only (`num`); airline is the IATA or ICAO code (`name`); `date` is `YYYYMMDD`.
