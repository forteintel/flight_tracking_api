# BA286 flight status example (September 2, 2026)

A live example of the FlightNerve `/airline` endpoint for **BA286** (British Airways, San Francisco to London), captured on September 2, 2026.

Get a free API key at [flightnerve.com/register](https://flightnerve.com/register/) and see the [endpoint reference](../docs/ENDPOINTS.md).

## Request

```bash
curl "https://api.flightnerve.com/airline/YOUR_API_KEY?num=286&name=BA&date=20260902"
```

The API key goes in the URL path. Flight number is digits only (`num`); airline is the IATA or ICAO code (`name`); `date` is `YYYYMMDD`.
