# LH400 flight status example (November 5, 2026)

A live example of the FlightNerve `/airline` endpoint for **LH400** (Lufthansa, Frankfurt to New York), captured on November 5, 2026.

Get a free API key at [flightnerve.com/register](https://flightnerve.com/register/) and see the [endpoint reference](../docs/ENDPOINTS.md).

## Request

```bash
curl "https://api.flightnerve.com/airline/YOUR_API_KEY?num=400&name=LH&date=20261105"
```

The API key goes in the URL path. Flight number is digits only (`num`); airline is the IATA or ICAO code (`name`); `date` is `YYYYMMDD`.
