# QF1 flight status example (November 3, 2026)

A live example of the FlightNerve `/airline` endpoint for **QF1** (Qantas, Sydney to London via Singapore), captured on November 3, 2026.

Get a free API key at [flightnerve.com/register](https://flightnerve.com/register/) and see the [endpoint reference](../docs/ENDPOINTS.md).

## Request

```bash
curl "https://api.flightnerve.com/airline/YOUR_API_KEY?num=1&name=QF&date=20261103"
```

The API key goes in the URL path. Flight number is digits only (`num`); airline is the IATA or ICAO code (`name`); `date` is `YYYYMMDD`.
