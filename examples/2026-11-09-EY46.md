# EY46 flight status example (November 9, 2026)

A live example of the FlightNerve `/airline` endpoint for **EY46** (Etihad, Dublin to Abu Dhabi), captured on November 9, 2026.

Get a free API key at [flightnerve.com/register](https://flightnerve.com/register/) and see the [endpoint reference](../docs/ENDPOINTS.md).

## Request

```bash
curl "https://api.flightnerve.com/airline/YOUR_API_KEY?num=46&name=EY&date=20261109"
```

The API key goes in the URL path. Flight number is digits only (`num`); airline is the IATA or ICAO code (`name`); `date` is `YYYYMMDD`.
