# CX252 flight status example (October 28, 2026)

A live example of the FlightNerve `/airline` endpoint for **CX252** (Cathay Pacific, Hong Kong to London), captured on October 28, 2026.

Get a free API key at [flightnerve.com/register](https://flightnerve.com/register/) and see the [endpoint reference](../docs/ENDPOINTS.md).

## Request

```bash
curl "https://api.flightnerve.com/airline/YOUR_API_KEY?num=252&name=CX&date=20261028"
```

The API key goes in the URL path. Flight number is digits only (`num`); airline is the IATA or ICAO code (`name`); `date` is `YYYYMMDD`.
