# UA1257 flight status example (September 15, 2026)

A live example of the FlightNerve `/airline` endpoint for **UA1257** (United, San Francisco to San Diego), captured on September 15, 2026.

Get a free API key at [flightnerve.com/register](https://flightnerve.com/register/) and see the [endpoint reference](../docs/ENDPOINTS.md).

## Request

```bash
curl "https://api.flightnerve.com/airline/YOUR_API_KEY?num=1257&name=UA&date=20260915"
```

The API key goes in the URL path. Flight number is digits only (`num`); airline is the IATA or ICAO code (`name`); `date` is `YYYYMMDD`.
