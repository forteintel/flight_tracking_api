# AA100 flight status example (November 10, 2026)

A live example of the FlightNerve `/airline` endpoint for **AA100** (American Airlines, New York to London), captured on November 10, 2026.

Get a free API key at [flightnerve.com/register](https://flightnerve.com/register/) and see the [endpoint reference](../docs/ENDPOINTS.md).

## Request

```bash
curl "https://api.flightnerve.com/airline/YOUR_API_KEY?num=100&name=AA&date=20261110"
```

The API key goes in the URL path. Flight number is digits only (`num`); airline is the IATA or ICAO code (`name`); `date` is `YYYYMMDD`.
