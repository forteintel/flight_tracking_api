# VS3 flight status example (October 29, 2026)

A live example of the FlightNerve `/airline` endpoint for **VS3** (Virgin Atlantic, London to New York), captured on October 29, 2026.

Get a free API key at [flightnerve.com/register](https://flightnerve.com/register/) and see the [endpoint reference](../docs/ENDPOINTS.md).

## Request

```bash
curl "https://api.flightnerve.com/airline/YOUR_API_KEY?num=3&name=VS&date=20261029"
```

The API key goes in the URL path. Flight number is digits only (`num`); airline is the IATA or ICAO code (`name`); `date` is `YYYYMMDD`.
