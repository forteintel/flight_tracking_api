# EK205 flight status example (August 18, 2026)

A live example of the FlightNerve `/airline` endpoint for **EK205** (Emirates, Dubai to New York via Milan), captured on August 18, 2026.

Get a free API key at [flightnerve.com/register](https://flightnerve.com/register/) and see the [endpoint reference](../docs/ENDPOINTS.md).

## Request

```bash
curl "https://api.flightnerve.com/airline/YOUR_API_KEY?num=205&name=EK&date=20260818"
```

The API key goes in the URL path. Flight number is digits only (`num`); airline is the IATA or ICAO code (`name`); `date` is `YYYYMMDD`.
