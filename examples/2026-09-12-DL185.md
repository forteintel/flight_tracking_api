# DL185 flight status example (September 12, 2026)

A live example of the FlightNerve `/airline` endpoint for **DL185** (Delta, Milan to New York), captured on September 12, 2026.

Get a free API key at [flightnerve.com/register](https://flightnerve.com/register/) and see the [endpoint reference](../docs/ENDPOINTS.md).

## Request

```bash
curl "https://api.flightnerve.com/airline/YOUR_API_KEY?num=185&name=DL&date=20260912"
```

The API key goes in the URL path. Flight number is digits only (`num`); airline is the IATA or ICAO code (`name`); `date` is `YYYYMMDD`.
