# SQ25 flight status example (September 3, 2026)

A live example of the FlightNerve `/airline` endpoint for **SQ25** (Singapore Airlines, Frankfurt to Singapore), captured on September 3, 2026.

Get a free API key at [flightnerve.com/register](https://flightnerve.com/register/) and see the [endpoint reference](../docs/ENDPOINTS.md).

## Request

```bash
curl "https://api.flightnerve.com/airline/YOUR_API_KEY?num=25&name=SQ&date=20260903"
```

The API key goes in the URL path. Flight number is digits only (`num`); airline is the IATA or ICAO code (`name`); `date` is `YYYYMMDD`.
